# AINE — Пилот: руководство для первого пользователя

**Цель:** сделать AINE «вторым мозгом» для одного реального человека и измерить пользу.

---

## 1. Кто может стать первым пользователем

Идеально — человек с ежедневными интеллектуальными задачами:
- **инженер/разработчик** (код, отладка, документация);
- **аналитик/исследователь** (поиск, обобщение, отчёты);
- **предприниматель/менеджер** (письма, планы, сводки);
- **врач/юрист/педагог** (справочные ответы, конспекты).

## 2. Как начать (5 минут)

1. Откройте кабинет AINE (`<your-domain>`);
2. Задайте первый вопрос в поле «Запрос для AINE»;
3. Оцените ответ (👍/👎) — так AINE учится на вас;
4. Раз в день задавайте AINE «что мне сегодня важного?»;
5. Копите пыльцу: чем больше вы используете AINE — тем точнее она к вам.

## 3. Типовые сценарии

| Сценарий | Пример запроса |
|---|---|
| 💻 Код | «напиши функцию парсинга CSV» |
| 📄 Документы | «сократи этот текст до 3 пунктов» |
| 🔍 Поиск | «что нового по теме X за неделю» |
| ✍️ Письма | «составь ответ клиенту вежливо» |
| 📊 Анализ | «сравни два варианта и предложи лучший» |
| 🧠 Память | «напомни, что мы решили вчера» |

## 4. Как измерять пользу (важно!)

Ведите простой журнал неделю:

| День | Задач решено с AINE | Часов сэкономлено | Точность (из 5) |
|---|---|---|---|
| Пн | | | |
| … | | | |

**Целевые метрики пилота:**
- ≥ 3 задачи в день решены быстрее;
- ≥ 2 часа в неделю сэкономлено;
- точность ответов ≥ 4 из 5 (с вашими 👍/👎 AINE растёт).

## 5. Что AINE даёт лично вам

1. **Память, которая не забывает** — накопленные ответы мгновенно (89× быстрее LLM);
2. **Суверенность** — всё локально, ваши данные не уходят наружу;
3. **Рост вместе с вами** — AINE запоминает ваши темы и становится точнее;
4. **Контроль** — вы всегда одобряете или отклоняете её действия.

## 6. Что мы попросим в конце пилота

- ваш отзыв: что было полезно, что нет;
- цифры журнала (часы, точность);
- разрешение использовать обезличенную историю как кейс.

---

*Пилот — это не демо, а проверка гипотезы: «AINE реально экономит время и растёт с пользователем».*
