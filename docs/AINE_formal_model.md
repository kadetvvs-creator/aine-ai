# Формальная модель живой памяти AINE

**Дата:** 09.11.2026
**Статус:** первая формализация на основе эмпирических замеров (бенчмарк 09.11.2026).

---

## 1. Определения

**Пыльца** — элементарная единица знания, кортеж:

```
p = (c, r, s, u, o)
  c — условие (строка-резонатор, до 120 символов)
  r — ответ (строка, до 500 символов)
  s ∈ [0, 1] — сила (вес, «здоровье» знания)
  u ∈ ℕ — число использований
  o — происхождение ∈ {seed, learned, infection, manual}
```

**Архетип** — агент Aᵢ со своим множеством пыльцы Pᵢ (12 архетипов).

**Геном** — G = {A₁ … A₁₂}, |G| = Σ|Pᵢ|.

## 2. Резонанс (извлечение знания)

**Токенизация условия:** cond(c) = {w ∈ c : len(w) ≥ 3} (слова русского/латинского алфавита).

**Jaccard-покрытие** (доля слов условия, встретившихся в запросе):

```
overlap(c, q) = |cond(c) ∩ cond(q)| / |cond(c)|
```

**Резонанс** (мера соответствия пыльцы запросу):

```
        ┌ overlap(c, q) · (0.5 + 0.5·s),  если overlap ≥ 0.5
ρ(p,q) = ┤
        └ 0,                              иначе
```

**Извлечение:** система отвечает из памяти пыльцой p* = argmax ρ(p,q), если ρ ≥ θ (порог θ = 0.4). Иначе — обращение к LLM (органу).

**Обоснование выбора Jaccard вместо косинуса:** эмпирически показано (4 эксперимента), что косинус nomic-embed даёт ложные срабатывания (87%) или полные промахи (0%), тогда как Jaccard даёт 40% покрытия при 0 ложных.

## 3. Эволюция силы (жизненный цикл)

**Усиление при использовании:**
```
s ← min(1, s + δ⁺),  u ← u + 1     (δ⁺ = 0.1)
```

**Угасание при неиспользовании** (за цикл эволюции):
```
s ← s − δ⁻,  если u = 0            (δ⁻ = 0.005)
```

**Смерть:** пыльца удаляется, если s < 0.05.

**Заражение:** пыльца с s ≥ 0.6 копируется случайному соседнему архетипу с o = infection.

**Инвариант:** знание «выживает» только при использовании — это давление отбора в сторону полезного.

## 4. Понятия и правила (обобщение)

**Кластер (понятие):** группа пыльцы с близкими условиями (Jaccard ≥ 0.5). |cluster| ≥ 2.

**Правило:** понятие → абстрактное «если [label] → то [лучший ответ]», где:
- label — наиболее частотное слово условия;
- лучший ответ — r пыльцы с максимальной силой;
- уверенность = max(s).

**Иерархия знаний:** пыльца (факты) → понятия (темы) → правила (обобщения).

## 6. Открытые вопросы (для продолжения)

1. **Повышение покрытия** без потери точности — улучшенная токенизация (синонимы, стемминг).
2. **Сходимость эволюции** — математическое доказательство, что сила стремится к 1 для полезной и к 0 для бесполезной пыльцы.
3. **Масштабируемость** — как покрытие зависит от размера генома (ожидается рост к ~80-90% при сотнях пыльцы).
