## 1. Итог одним абзацем

AINE — **трёхслойная био-вдохновлённая система** (геном/орган/тело) на базе локальных LLM,
к которой за текущий цикл добавлены **четыре новых «столпа» самоулучшения**:

1. **Геном 2.0** — семантический резонанс (эмбеддинги вместо подстроки);
2. **Саморефлексия** — генерация → критика → улучшение;
3. **Нейро-символьный слой** — правила «если → то» с уверенностью;
4. **Оркестрация** — голос 8B / орган 35B / инструменты.

Результат: AINE перешла от «память + LLM» к **живой самоулучшающейся системе**,
работающей полностью локально.

## 2. Три слоя (архитектура)

```
СЛОЙ 1: ГЕНОМ (личность/память)  ← 12 архетипов, 161 пыльца (все с эмбеддингами)
        │ резонанс (семантический)
СЛОЙ 2: ОРГАН (мозг по вызову)   ← Qwen3.6-35B / Qwen3-Coder-30B / Gemma-26B / Qwen3.8-27B
        │ задачи
СЛОЙ 3: ТЕЛО (исполнение)        ← инструменты (файлы/код/поиск/погода) + сервисы
```

**Ключевой принцип:** личность (геном) переживает замену мозга; мозг можно апгрейдить, не трогая личность.

## 3. Четыре столпа «прорыва» (реализовано)

### 3.1. Геном 2.0 — семантическая память
- **Было:** резонанс = подстрока (`cond in req`) — почти никогда не срабатывал.
- **Стало:** эмбеддинг запроса × эмбеддинг пыльцы → косинус → резонанс.
- **Backfill:** все 161 пыльцы обогащены эмбеддингами (nomic-embed, 768 dim).
- **Порог:** 0.62 (отсекает ложные срабатывания).
- Проверено: парафраз «какие направления будут расти» → нашёл «стратегические прогнозы» (0.53).

### 3.2. Саморефлексия
- После генерации ответа «проверщик» критикует (ДА/НЕТ + почему).
- При «НЕТ» — улучшение с учётом критики.
- Включена флагом `SELF_REFLECT=1`, срабатывает только на плохие ответы (не тормозит норму).

### 3.3. Нейро-символьный слой
- Сильная пыльца (сила ≥0.6) → **символьное правило** «если → то (уверенность, uses)».
- Эндпоинт `/api/aine/rules` + таблица правил в кабинете (вкладка «Знания»).
- Правила не галлюцинируют: это проверенные шаблоны, растут по мере использования.

### 3.4. Оркестрация
- **Голос** (Qwen3-8B, fast :8095) — простые вопросы, мгновенно.
- **Орган** (Qwen3.6-35B, organ :8080) — сложные задачи (по ключевым словам: создай/напиши/проанализируй…).
- **Инструменты** — web_search, write_file, read_file, run_command, git, get_weather.

### 3.5. Живая память (понятия → обобщение → правила)
- **Семантическая кластеризация** пыльцы в «понятия» (косинус эмбеддингов, порог 0.8, фиксированное ядро — без дрейфа центроида).
- **Обобщение**: понятие → абстрактное правило «если [тема] → то [ответ]» с уверенностью.
- **Саморастущие правила**: сила растёт от использования (резонанс → strength↑) → пыльца становится правилом (≥0.6).
- **Результат**: 161 пыльца → **15 осмысленных понятий** (кибербезопасность, LoRA, ИИ, экономика, кадры, качество…).
- **Отображение**: вкладка «ВКМ AINE → Рост → Понятия генома» (таблица «если → то»).

Иерархия знаний: **факты (пыльца) → понятия (темы) → правила (если→то)** — растёт само.

### 3.6. Самоинженерия и стратегия саморазвития (12 путей)
- **Самоинженерия**: AINE пишет себе код → тестирует → отлаживает (в песочнице `selfengineered/`).
- **Стратегия 12 путей**: 12 архетипов = 12 путей развития; движок оценивает ценность/риск каждого → выбирает **оптимальный**, при отказе — **альтернативный**.
- **Контроль версий + откат**: бэкап `.bak-<id>` перед применением; **проверка влияния** (health-check нескольких endpoint'ов); **авто-откат** при недочёте.
- **Переосмысление**: провалы путей фиксируются → стратегия их учитывает и не повторяет.
- **Одобрение человеком**: кнопки ✅/❌ в кабинете (вкладка «Автономия → Предложения»).
- **Рост уровня**: L1 (точечная правка) → L4 (фичи + обоснование) по мере одобрений.

## 4. Полный цикл запроса (актуальный)

```
Запрос
   │
   ├─ 1. Символьное правило (сила ≥0.6) ── точное совпадение ──→ детерминированный ответ
   │
   ├─ 2. Резонанс памяти (семантика, ≥0.62) ── похожий смысл ──→ мгновенный ответ
   │
   ├─ 3. Оркестрация: простое → голос 8B / сложное → орган 35B
   │
   ├─ 4. Саморефлексия: проверщик критикует → при «НЕТ» улучшает
   │
   └─ 5. Барьер постулатов → самообучение → пыльца (origin=learned)
            → растёт сила → становится правилом
```

## 7. Ограничения и следующие шаги

1. **LoRA-дообучение на CPU отключено** — непрактично без CUDA. Путь: внешняя GPU или «голос» 3B.
2. **Символьных правил пока мало (2)** — они появятся по мере использования пыльцы (резонанс → сила → правило).
3. **Понятия (кластеризация пыльцы)** — API есть, но без живого UI-отображения.
4. **Дальше по мастер-плану:** песочница, мета-обучение, рекурсивные планы.
