# AINE — Pilot: Guide for the First User

**Goal:** make AINE a "second brain" for one real person and measure the benefit.

---

## 1. Who can be the first user

Ideally — a person with daily intellectual tasks:
- **engineer/developer** (code, debugging, documentation);
- **analyst/researcher** (search, summarization, reports);
- **entrepreneur/manager** (emails, plans, briefs);
- **doctor/lawyer/teacher** (reference answers, notes).

## 2. How to start (5 minutes)

1. Open the AINE cabinet (`<your-domain>`);
2. Ask the first question in the "Query for AINE" field;
3. Rate the answer (👍/👎) — this is how AINE learns from you;
4. Once a day ask AINE "what is important for me today?";
5. Accumulate pollen: the more you use AINE — the more accurate it becomes for you.

## 3. Typical scenarios

| Scenario | Example query |
|---|---|
| 💻 Code | "write a CSV parsing function" |
| 📄 Documents | "shorten this text to 3 points" |
| 🔍 Search | "what is new on topic X this week" |
| ✍️ Emails | "write a polite reply to the client" |
| 📊 Analysis | "compare two options and suggest the best" |
| 🧠 Memory | "remind me what we decided yesterday" |

## 4. How to measure the benefit (important!)

Keep a simple journal for a week:

| Day | Tasks solved with AINE | Hours saved | Accuracy (out of 5) |
|---|---|---|---|
| Mon | | | |
| … | | | |

**Pilot target metrics:**
- ≥ 3 tasks per day solved faster;
- ≥ 2 hours per week saved;
- answer accuracy ≥ 4 of 5 (with your 👍/👎 AINE grows).

## 5. What AINE gives you personally

1. **Memory that does not forget** — accumulated answers instantly (89× faster than LLM);
2. **Sovereignty** — fully local, your data does not leave;
3. **Growth with you** — AINE remembers your topics and becomes more accurate;
4. **Control** — you always approve or reject its actions.

## 6. What we ask at the end of the pilot

- your feedback: what was useful, what was not;
- the journal numbers (hours, accuracy);
- permission to use an anonymized story as a case study.

---

*The pilot is not a demo — it is a test of the hypothesis: "AINE really saves time and grows with the user".*
