## 1. Методика

Набор из 15 вопросов (10 «своих» — темы генома, 5 «чужих» — контрольные).
Каждый вопрос идёт через резонанс памяти; при попадании — ответ из памяти, при промахе — прямой LLM (Qwen3.6-35B).
Метрики: **покрытие** (% попаданий), **задержка**, **токены**, **ложные срабатывания**.

## 4. Выводы (научные)

1. **Семантический резонанс на nomic-embed — опровергнут**: 768-мерный эмбеддинг не разделяет парафраз и чужой текст (косинусы в узкой полосе 0.5–0.8).

2. **Гибридное словесное сопоставление (Jaccard) — работает**: точное/близкое совпадение слов даёт надёжный ответ из памяти.

3. **Честное позиционирование памяти**: быстрый кэш точных знаний (89× скорость, 0 токенов, 100% точность), а не «понимание смысла».
