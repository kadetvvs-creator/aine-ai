# Contributing to AINE

Спасибо, что помогаете AINE расти. Проект строится на трёх принципах: **живое, контролируемое, воспроизводимое**.

## Принципы участия

1. **Каждое изменение — через Pull Request.** Никаких прямых коммитов в `main`.
2. **Сначала измерь, потом меняй.** Если вы меняете память/резонанс — прогоните `code/benchmark.py` и приложите цифры.
3. **Уважай архитектуру.** Геном (личность) переживает замену мозга. Не смешивайте слои: геном → память, орган → LLM, тело → инструменты.
4. **Автономия под контролем.** Любой автономный шаг AINE должен иметь человеческое вето. Не удаляйте барьер и kill-switch.

## Как внести вклад

```bash
# 1. форк + клонирование
git clone https://github.com/ВАШ_ЛОГИН/aine-ai.git
cd aine-ai

# 2. ветка
git checkout -b feat/мое-изменение

# 3. изменение + тест
python3 code/benchmark.py   # убедиться, что не сломалось

# 4. коммит + PR
git commit -m "feat: описание"
git push origin feat/мое-изменение
```

## Структура репозитория

```
code/    — движок (ail.py), саморазвитие (self_improve.py), бенчмарк
docs/    — статус, бенчмарк, формальная модель, развёртывание
docker/  — Dockerfile + docker-compose (запуск одной командой)
```

## Стиль кода

- Python 3.12+, только стандартная библиотека для движка (`ail.py`);
- Комментарии — на русском, краткие;
- Новые возможности — через «предложение» (PR с описанием слабости и фикса), как делает сама AINE.

## Куда смотреть

Откройте Issue — отвечаем. Приветствуются: улучшение покрытия памяти, red-team-отчёты, оптимизация эволюции.
